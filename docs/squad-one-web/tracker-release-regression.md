## Credential mechanism found in the baseline

`test_hosted_dashboard_acceptance.py` generated random passwords for temporary admin, staff and Squad accounts, passed them to the child through stdin, and removed the accounts afterward. Passwords were not saved in its checkpoint or evidence. Its management API helper resolves an environment variable or a macOS Keychain entry; that is infrastructure authorization, not an existing staff login. No credential value was read during this inspection, and no new account or password was created.

There is consequently no reusable staff test credential supplied by this historical acceptance. A final real staff smoke must consume a parent-provided, already-authorized existing staging staff session or credential through memory/stdin, bind the returned Auth UUID to the expected identity, and verify the actual public profile. Never infer staff membership from a Squad role, create/promote a profile, reset a real user's password, or treat a service-role API key as a browser session. No such hosted run has been executed by the UI lane.

## Required network boundaries

- Forward application static GET/HEAD requests only to the exact approved frontend origin. Forward API requests only to `https://scvojtvgnkmbupvyslmb.supabase.co`; reject DigitalOcean, the old API, production Supabase and arbitrary remote origins.
- Allow Auth identity/session operations only as required by the supplied session protocol. Raw public-table access is restricted to explicit existing Tracker read tables with GET/HEAD and the public schema; no generic RPC GET allowance. This exception is for the legacy Tracker, not new Squad screens.
- The native dashboard RPC is allowed only with `Content-Profile: canto_api` and read actions `capabilities`, `query`, `customer_options` or `export_read`; actions such as customer saves, archives and export starts remain denied. Read actions must have valid JSON bodies. Existing media signed-link generation may be allowed only for the exact `canto-media` bucket, bounded paths and expiry; it does not authorize uploads, removals or attachment changes.
- Supabase Masters uses `POST /rest/v1/rpc/masters` with `Content-Profile: canto_api`, an exact selected resource, and action `list` or `get`; it is not the old proxy function. Data Refresh permits only `canto-refresh` with action `status` and environment `staging`; media status permits only its existing read RPC. Do not reuse the old script's denylist as a general network policy.
- Explicitly deny `set_my_dashboard_presence`, `promote_stale_new_orders_to_pending`, all profile insert/update, and every other unlisted mutation. Denied calls must return a clear failure, not a fabricated successful write response.
- Disable actual WebSocket transport before application evaluation. A local subscription test double can preserve rendering without sending presence or other messages; report realtime as untested. Request interception alone does not fence WebSocket traffic.
